# Sample captures

Both bundled captures are deterministic synthetic fixtures. They use `.lscap`
version 1.1 and set metadata flag bit 2 on every record. They are suitable for
UI, parser, and decoder demonstrations. They are not evidence of over-the-air
traffic.

## `sample-mesh-traffic.lscap`

A deterministic synthetic 24-frame demo of the US LongFast slot (906.875 MHz,
SF11/BW250/CR4:5), generated by `scripts/generate_sample_capture.py` — no
radio required. It contains ordinary Meshtastic, MeshCore, and Reticulum
traffic, one CRC failure, one truncated frame, and at **sequence 9 a Shelby
off-grid pointer** (`SHLB`) riding behind a 16-byte protocol header.

Try it:

- **Web analyzer** — open the TRAFFIC screen at the deployed web app and
  press **Sample** (the app bundles this file), or choose *Open .lscap* and
  pick it yourself. Frame 9 is marked `◆ SHLB`; selecting it shows the
  decoded pointer beside the hex dump.
- **Command line** —

  ```sh
  python3 scripts/lscap.py validate samples/sample-mesh-traffic.lscap
  python3 scripts/shelby_pointer.py scan samples/sample-mesh-traffic.lscap
  ```

Regenerate (always produces identical bytes):

```sh
python3 scripts/generate_sample_capture.py
```

## `field-capture-0846.lscap`

A pointer-free synthetic companion with the same traffic shape. Generate it
with:

```sh
python3 scripts/generate_sample_capture.py --plain
```

The pointer embedded in `sample-mesh-traffic.lscap` uses an immutable Shelby
commitment published before the provenance update. This regenerated local
fixture does not replace that remote object.
