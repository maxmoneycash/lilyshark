Flash a T-Deck from this page.

Lilyshark turns a LILYGO T-Deck into a handheld LoRa packet sniffer and RF analyzer. Installing it takes one cable and one click — no toolchain, no downloads, nothing to compile.

INSTALL // v0.1.0-alpha.7

  1. Plug the T-Deck into this computer with a USB-C data cable (charge-only cables are the most common failure).
  2. Turn the device on — the side switch must be up or the radio never appears on USB.
  3. Click install and pick the port that mentions USB JTAG/serial. The flash takes about a minute; the device reboots into Lilyshark by itself.
This browser has no Web Serial — open this page in Chrome or Edge on a computer. Serial access is blocked here; check the browser's site permissions. writes the complete image · nothing else required

IF THE DEVICE NEVER APPEARS
· Swap the cable first — most "broken" flashes are charge-only cables. · Force the bootloader: hold the trackball center down, press the reset button, release both, then click install again. · Close other tabs or serial monitors using the port; only one program can hold it. · The image is unbrickable to experiment with: it writes the full flash from byte zero, so a failed attempt is cured by flashing again.
WHAT GETS INSTALLED
The same factory image the repository builds: the complete Lilyshark firmware — live traffic, packet inspector, spectrum scan, node tracking, surveys, capture to microSD, and the Shelby off-grid pointer pipeline. Source, checksums, and reproducible-build instructions: github.com/maxmoneycash/lilyshark After flashing, open the analyzer, press CONNECT → LILYSHARK T-DECK · USB, and the device links to this site over the same cable.
