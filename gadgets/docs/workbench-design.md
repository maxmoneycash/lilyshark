# Discovery and build design

September 15, 2026. Applied `product-frontend-design` and `web-design-guidelines`.

## The job

Give experienced hardware hobbyists a reason to explore something, a useful way to try it, and a credible route to building their own version. The primary content is the working idea and its evidence. Device comparisons remain a supporting tool.

## Page hierarchy

- **Discover:** compact navigation → one clear headline/search → interest links → a photographed project with a demo → selected hardware → an invitation to show a build.
- **Build:** physical object and purpose → interactive sample → method and evidence → exact parts/firmware path → adaptation.
- **Hardware:** searchable directory with its original source notes, practical requirements and filters.

The homepage leads with one real project rather than a fabricated feed. Maker images are visibly separate from the project photo. The build page distinguishes the synthetic fixture, the simulated photographed display and the live tests recorded in the repository.

## Visual decisions

Instrument Sans provides a shared reading/display family. Cool neutral surfaces, dark ink, restrained blue interaction states and a dark feature panel frame original hardware photography. Navigation stays small. Technical labels and packet measurements become denser only inside the demo.

At small widths the photo stacks above its description; the first action fits within an ordinary phone-height preview. Packet filters collapse the list when one result remains. Raw bytes and section navigation scroll within their containers rather than widening the document. Existing setup and research layouts use the same typography and colors.

No decorative animation, gradient artwork, invented engagement counts or fake builder identities were added. The actual browser screenshots and interaction record are in [verification.md](verification.md).

## Limits and next evidence

The local page is a demonstrable product flow, not proof of an audience or business. No visitor study has accepted this design yet. A live workflow video and an independently reproduced tutorial remain the next content milestone. Public hosting, durable creator pages and share images remain outstanding. The [maker pilot](strategy/maker-pilot-offer.md) is a proposed commercial test, not a product already for sale.
