## Objections to learn from

| Objection | Useful response |
| --- | --- |
| “What is your reach?” | Say there is no established audience to sell. The fee buys defined production assets for the maker's channels. If they only want media distribution, this offer is not a fit. |
| “We already have a product page.” | Show the specific missing outcome/parts/revision path. If it is already excellent, acknowledge that and qualify a different seller. |
| “I can make a page for free.” | Agree that templates and publishing tools can be free. Ask whether source reconciliation, writing and asset preparation is work they value outsourcing. |
| “Can you guarantee sales?” | No. Acceptance covers the agreed production and functionality. Ask what observable use would make the asset valuable to them. |
| “Can you do a full hardware review?” | Quote a separate physically tested scope after feasibility. The $750 package checks sources and packages approved existing material. |
| “Can you just take commission?” | Discuss only with a real attribution agreement and plausible sales volume. At a $6 platform commission, 125 approved orders merely match $750 in gross receipts before labor. |

Log objections in the prospect record; do not bury contradictory feedback in a list of positive replies. No template should be sent automatically or to unqualified bulk lists.
